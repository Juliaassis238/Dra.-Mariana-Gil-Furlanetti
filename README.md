# Dra. Mariana Gil Furlanetti — Modelo 1

Versão institucional em HTML, CSS e JavaScript puros. A composição preserva o princípio do primeiro modelo de referência: retrato editorial ocupando toda a capa, navegação por âncoras e seções de apresentação, áreas de atuação, atendimento e contato.

## Materiais e revisão antes de publicar

O projeto usa dois retratos editoriais gerados a partir de um retrato profissional público, fotos fornecidas pelo usuário da sala de atendimento e recepção, e um monograma MGF recriado a partir da imagem de perfil. As fotos reais do consultório possuem versões móveis em WebP para carregar com mais rapidez. Antes da publicação comercial definitiva, confirme a autorização de uso das imagens e revise CRM, RQE, endereço, telefone, serviços e disponibilidade.
